# The Groceries Code Adjudicator Act 2013 (Commencement) Order 2013

Made: 23rd May 2013

The Secretary of State makes the following Order in exercise of the powers conferred by section 25(1) of the Groceries Code Adjudicator Act 2013[^f00001].

#### Citation

###### 1

This Order may be cited as the Groceries Code Adjudicator Act 2013 (Commencement) Order 2013.

#### Commencement

###### 2

Sections 1 to 21 and the Schedules to the Groceries Code Adjudicator Act 2013 come into force on 25th June 2013.

## Signed

Jo Swinson — Parliamentary Under Secretary of State for Employment Relations and Consumer Affairs — Department for Business, Innovation and Skills — 23rd May 2013

## Explanatory note

(This note is not part of the Order)

EXPLANATORY NOTE

This Order brings into force on 25th June 2013 those provisions of the Groceries Code Adjudicator Act 2013 which are not already in force.
