# The Code of Practice (Disciplinary and Grievance Procedures) Order 2015

Made: 10th March 2015

In accordance with section 200(5) the Secretary of State makes the following Order.

#### Citation

###### 1

This Order may be cited as the Code of Practice (Disciplinary and Grievance Procedures) Order 2015.

#### Appointed day for the Code of Practice

###### 2

The revised Code of Practice on disciplinary and grievance procedures, issued by ACAS on 10th March 2015 comes into effect on 11th March 2015.

## Signed

Jo Swinson — Parliamentary Under Secretary of State for Employment Relations and Consumer Affairs — Department for Business, Innovation and Skills — 10th March 2015

## Explanatory note

(This note is not part of the Order)

EXPLANATORY NOTE

This Order appoints 11th March 2015 as the day upon which the revised Code of Practice on disciplinary and grievance procedures, which has been issued by ACAS under section 199 of the Trade Union and Labour Relations (Consolidation) Act 1992, will come into effect.

An impact assessment has not been prepared for this Order as the revised Code of Practice does not create any rights or obligations and it does not create any additional burdens on business.
