# The Local Government Act 2000 (Model Code of Conduct) (Amendment) Order 2002

Made: 4th July 2002

Laid before Parliament: 5th July 2002

Coming into force: 27th July 2002

The Secretary of State, in exercise of the powers conferred upon him by sections 50(1) and 105(2), (3) and (4) of the Local Government Act 2000[^f00001] hereby makes the following Order:

#### Citation and application

###### 1

- (1) This Order may be cited as the Local Government Act 2000 (Model Code of Conduct) (Amendment) Order 2002.

- (2) This Order applies in relation to England and to police authorities in Wales[^f00002].

#### Amendment to the Local Authorities (Model Code of Conduct) (England) Order 2001

###### 2

In article 4(1) of the Local Authorities (Model Code of Conduct) (England) Order 2001[^f00003], for the words preceding sub-paragraph (a) there shall be substituted “Where an authority has adopted a code of conduct or such a code applies to it, the following shall, where applicable to the authority, be disapplied as respects that authority—”[^f00004].

#### Amendment to the Parish Councils (Model Code of Conduct) Order 2001

###### 3

In article 3(1) of the Parish Councils (Model Code of Conduct) Order 2001[^f00005], for the words preceding sub-paragraph (a) there shall be substituted “Where an authority has adopted a code of conduct or such a code applies to it, the following shall, where applicable to the authority, be disapplied as respects that authority—”.

#### Amendment to the National Park and Broads Authorities (Model Code of Conduct) (England) Order 2001

###### 4

In article 3(1) of the National Park and Broads Authorities (Model Code of Conduct) (England) Order 2001[^f00006], for the words preceding sub-paragraph (a) there shall be substituted “Where an authority has adopted a code of conduct or such a code applies to it, the following shall, where applicable to the authority, be disapplied as respects that authority—”.

#### Amendment to the Police Authorities (Model Code of Conduct) Order 2001

###### 5

In article 3(1) of the Police Authorities (Model Code of Conduct) Order 2001[^f00007], for the words preceding sub-paragraph (a) there shall be substituted “Where an authority has adopted a code of conduct or such a code applies to it, the following shall, where applicable to the authority, be disapplied as respects that authority—”.

## Signed

Signed by authority of the Secretary of State

Nick Raynsford — Minister of State, — Office of the Deputy Prime Minister — 4th July 2002

## Explanatory note

(This note is not part of the Order)

This Order makes amendments to the Local Authorities (Model Code of Conduct) (England) Order 2001, the Parish Councils (Model Code of Conduct) Order 2001, the National Park and Broads Authorities (Model Code of Conduct) (England) Order 2001 and the Police Authorities (Model Code of Conduct) Order 2001. The amendments disapply the specified enactments to authorities where a code of conduct in the schedules to those orders has been adopted or applied to it. This replaces a temporary disapplication until 27th July 2002.
