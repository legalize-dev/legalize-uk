| --- | --- |
| *Microbiological parameters* | *Limit* |
| Total aerobic bacteria | 10³/g |
| Coliforms (30°C) | 0/g |
| Coliforms (44.5°C) | 0/10g |
| Anaerobic sulphite–reducing bacteria (no gas production) | 10/g |
| *Clostridium perfringens* | 0/g |
| *Staphylococcus aureus* | 0/g |
| *Salmonella* | 0/25g |
| **Residues** |  |
| *Elements* | *Limit* |

| Pb | 5 ppm |
| Cd | 0.5 ppm |
| Hg | 0.15 ppm |
| Cr | 10 ppm |
| Cu | 30 ppm |

| Moisture (105°C) | 15% |
