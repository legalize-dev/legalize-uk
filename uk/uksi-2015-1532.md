## SCHEDULE 1 — Modifications of sections 27 and 42 of the Immigration, Asylum and Nationality Act 2006 as those sections extend to Jersey

| Provision | Modifications |
| --- | --- |
| Section 27 *(Documents produced or found)* | In the substituted paragraph 4(4)(b) for “the United Kingdom” substitute “the Bailiwick of Jersey”; |
|  | In the substituted paragraph 4(4)(c) omit “in respect of an appeal under the Immigration Acts or” |
|  |  |
| Section 42 *(Information: embarking passengers)* | In subsection (2) for “the United Kingdom” wherever it occurs substitute “the Bailiwick of Jersey”. |

## SCHEDULE 2 — Modifications of sections 67 and 73(6) of, and Schedule 8 and Parts 1 and 10 of Schedule 9 to, the Immigration Act 2014 as those provisions extend to Jersey

| Provision | Modifications |
| --- | --- |
|  |  |
| Schedule 8 |  |
| Paragraph 4*(Embarkation cards)*(amending paragraph 5 of Schedule 2 to the 1971 Act) | In sub-paragraph (3) for “United Kingdom” substitute “Bailiwick of Jersey”. |
|  |  |
| Paragraph 5*(Designations)*(inserting new paragraph 5A of Schedule 2 to the 1971 Act) | In the inserted paragraph 5A—for “Secretary of State” wherever it appears substitute “Minister”; |
|  |  |
|  | . . . |
|  | after sub-paragraph (6) insert—7In this Schedule “Minister” means Minister for Home Affairs.. |
|  |  |
| Paragraph 6*(Directions to carriers and operators of ports)*(inserting new paragraph 5B of Schedule 2 to the 1971 Act) | In the inserted paragraph 5B for “Secretary of State” in sub-paragraph (1) substitute “Minister”; |
|  |  |
| Schedule 9 |  |
| Part 1*(Provision relating to removal)* | in paragraph 1 for “Secretary of State” substitute “ Minister ”.omit paragraphs 2 to 7 (inclusive) |
|  |  |
| Part 10*(Provision relating to embarkation checks)* | In sub-paragraph (3) after “comes into force” insert “in the Bailiwick of Jersey”. |

## Signed
