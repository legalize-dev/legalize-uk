## SCHEDULE 1 — Entries to be substituted in Table A (vitamins in respect of which claims may be made) in Schedule 6, Part II, to the Food Labelling Regulations (Northern Ireland) 1996

| *Column 1* *Vitamin* | *Column 2* *Recommended Daily Allowance* |
| --- | --- |
| Vitamin A | 800 μg |
| Vitamin D | 5 μg |
| Vitamin E | 12 mg |
| Vitamin K | 75 μg |
| Vitamin C | 80 mg |
| Thiamin | 1.1 mg |
| Riboflavin | 1.4 mg |
| Niacin | 16 mg |
| Vitamin B6 | 1.4 mg |
| Folic acid | 200 μg |
| Vitamin B12 | 2.5 μg |
| Biotin | 50 μg |
| Pantothenic acid | 6 mg |

| Magnesium | 375 mg |
