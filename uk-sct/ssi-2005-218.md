## PART 3 — Microbiological and residues criteria for collagen intended for human consumption

| Microbiological parameters | Limit |
| --- | --- |
| Total aerobic bacteria | 10³/g |
| Coliforms (30°C) | 0/g |
| Coliforms (44.5°C) | 0/10g |
| Anaerobic sulphite–reducing bacteria (no gas production) | 10/g |
| *Clostridium perfringens* | 0/g |
| *Staphylococcus aureus* | 0/g |
| *Salmonella* | 0/25g |

| Elements | Limit |
| --- | --- |
| As | 1 ppm |
| Pb | 5 ppm |
| Cd | 0.5 ppm |
| Hg | 0.15 ppm |
| Cr | 10 ppm |
| Cu | 30 ppm |
| Zn | 50 ppm |
| Moisture (105°C) | 15% |
| Ash (550°C) | 2% |
| SO₂ (Reith Williems) | 50 ppm |
| H₂O₂ (European Pharmacopia 1986 (V₂O₂)) | 10 ppm |
